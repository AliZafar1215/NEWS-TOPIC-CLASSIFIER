News Topic Classifier Using BERT
This project uses BERT to classify news headlines into different categories.
1. Categories
World
Sports
Business
Sci/Tech

2. Tools Used
Python
BERT
PyTorch
Hugging Face Transformers
Scikit-learn

3. Dataset
AG News Dataset

4. How to Run
Install libraries:
pip install transformers datasets torch scikit-learn
Run the notebook:
Task_1_News_Topic_Classifier_BERT.ipynb

5. Features
Loads news dataset
Tokenizes text using BERT tokenizer
Trains BERT model
Predicts news category
Evaluates model accuracy
